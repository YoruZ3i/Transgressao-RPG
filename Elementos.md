A seguir vem as regras dos Elementos do Paranormal e como trazê-los para a Realidade:
#### Elemento de Sangue
O Elemento de Sangue, um elemento Primário. Ele é uma das pontes do Outro Lado para a Realidade as suas maneiras de enviar ele são:

- [ ] Mortes de Maneira brutal e Sanguinária.

- [ ] Sacrifícios de Sangue para a sua entidade.

- [ ] [[Sigilos de Eloquência]] que invocam o Elemento de Sangue.
##### Elemento de Intenção 
Uma união entre dois elementos sendo só possível pelo elemento de Medo. A junção de Sangue e Conhecimento foram a Intenção:

- [ ] Mortes de Maneira brutal e Sanguinária.

- [ ] Sacrifícios de Sangue para a sua entidade.

- [ ] [[Sigilos de Eloquência]] que invocam o Elemento de Intenção.

- [ ] Aceitar a "Natureza de uma Verdade" que algo/alguém esconde.
#### Elemento de Conhecimento
O Elemento de Conhecimento, um elemento Primário. Ele é uma das pontes do Outro Lado para a Realidade as suas maneiras de enviar ele são:

- [ ] Mortes que foram derivadas de uma descoberta ou ocultação.

- [ ] Armazenar o Conhecimento de um evento Paranormal.

- [ ] [[Sigilos de Eloquência]] que invocam o Elemento de Conhecimento 
##### Elemento de Transmissão 
Uma união entre dois elementos sendo só possível pelo elemento de Medo. A junção de Conhecimento e Energia forma a Transmissão:

- [ ] Espalhar um Conhecimento que deveria ser oculto.

- [ ] Ser um só Com Algo.

- [ ] [[Sigilos de Eloquência]] que invocam o Elemento de Transmissão (os Sinais).
#### Elemento de Energia
O Elemento de Energia, um elemento Primário. Ele é uma das pontes do Outro Lado para a Realidade as suas maneiras de enviar ele são:

- [ ] Mortes derivadas de azar ou de Desastres.

- [ ] Objetos elétricos funcionando de maneira anormal.

- [ ] [[Sigilos de Eloquência]] que invocam o Elemento de Energia
##### Elemento de Destruição 
Uma união entre dois elementos sendo só possível pelo elemento de Medo. A junção de Energia e Morte forma a Destruição:

- [ ] Mortes derivadas de Desastres e Desgaste Mental.

- [ ] Uma Destruição em Massa de algo ou de dezenas de pessoas.

- [ ] [[Sigilos de Eloquência]] que invocam o Elemento de Destruição
#### Elemento de Morte
O Elemento de Morte, um elemento Primário. Ele é uma das pontes do Outro Lado para a Realidade as suas maneiras de enviar ele são:

- [ ] Mortes causadas pela passagem inevitável do tempo.

- [ ] Repetição de acontecimentos e momentos.

- [ ] [[Sigilos de Eloquência]] que invocam o Elemento de Morte.
##### Elemento de Percepção
Uma união entre dois elementos sendo só possível pelo elemento de Medo. A junção de Morte e Sangue forma a Percepção:

- [ ] Mortes utilizando o Lodo Preto da Morte e para causar um sentimento >único< a quem ver a vítima.

- [ ] Reviver sentimentos únicos através do Lodo de Contemplação.

- [ ] [[Sigilos de Eloquência]] que invocam o Elemento de Percepção.

Uma união entre dois elementos sendo só possível pelo elemento de Medo. A junção de Sangue e Energia formam Tentação:
